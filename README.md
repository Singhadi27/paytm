# 🚀 Version Control Practice Repository

Welcome to my GitHub repo where I'm practicing and mastering **version control** using Git and GitHub.  
This is a personal learning space to explore how Git works, from basic commands to collaborative workflows.

---

## 📌 What I'm Learning

- ✅ Git basics: `init`, `add`, `commit`, `status`, `log`
- ✅ Working with branches and merge conflicts
- ✅ GitHub remote workflows: `clone`, `push`, `pull`, `fetch`
- ✅ `.gitignore` usage
- ✅ Reverting changes and Git history
- ✅ Using GitHub for collaboration (PRs, forks, issues)

---

## 🛠️ Tools Used

- [Git](https://git-scm.com/) – for local version control  
- [GitHub](https://github.com/) – for remote repository hosting  
- VS Code – as my code editor with Git integration  

---

## 🎯 Goal

To become confident with Git and GitHub so I can:
- Contribute to open source
- Collaborate better on team projects
- Use version control professionally in DevOps and software development
